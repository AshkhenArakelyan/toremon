# Toremon App

## Overview

A personal task management application.

## Features

- Authentication
- Create task lists
- Create tasks
- Mark tasks as completed
- Track progress

## Tech Stack

- React.js
- TypeScript
- Vite
- Zustand
- TanStack Query
- Laravel
- MySQL

## Prerequisites

- **Node.js**: v20+
- **npm**: v10+
- **PHP**: v8.2+
- **Composer**: v2+
- **MySQL**: v8+
